# Round Two Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the agent-overload fixes correct under adversarial input, measured with confidence intervals against a fair baseline, and extended with three research-backed, evaluator-verified improvements.

**Architecture:** All changes stay inside the existing seams: `AgentRegistry.select/find_duplicate`, `AgentMemory.compact/render_history`, `gmail/prefilter.py`, `llm/gateway.py`, `openrouter_client/anthropic_native.py`, the execution runtime, and the evaluators in `evals/`. New behaviour is either a pure fix or lives behind a `RegistryConfig`/`MemoryConfig` field with an env override. Every task starts with a failing test at the existing single LLM chokepoint.

**Tech Stack:** Python 3.10+, pytest + pytest-asyncio (auto mode), rank-bm25, httpx, FastAPI. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-31-round-two-design.md`

## Global Constraints

- Python 3.10+; no new packages.
- When every flag is at its upstream value (`OPENPOKE_ROSTER_STRATEGY=all`, `OPENPOKE_AGENT_MEMORY=0`, `OPENPOKE_ROUTING=strong_only`), behaviour must not change; `test_all_strategy_matches_upstream_rendering` and `test_strong_only_mode_reproduces_upstream` must keep passing.
- Offline evals and tests need no network.
- Live budget for section D: about $10.
- Commit after every task; messages end with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.

## Review Focus

1. An email with no `clean_text` (body None) and a bulk label: prefilter must return keep, never raise. Test added to Task 1.
2. Compaction scheduled in the background while the process shuts down: the task must be awaited or cancelled cleanly, never leave a half-written file. Atomic write in Task 2 covers the file; Task 2 test covers the scheduling.
3. A registry with more pinned agents than `max_roster`: `select()` must still return at most `max_roster` and prefer the most recent pinned. Test added to Task 6.
4. A commitment sentence longer than 500 chars or with XML characters: stored truncated to 300 chars, escaped on render. Test added to Task 11.
5. `search_history` called with an empty query or on an agent with no log: returns an empty match list, never an exception. Test added to Task 12.
